Behind the games

What I build

I work across the full Unity production stack—from the interaction players touch to the shared systems that keep multiple games reliable and easier to maintain.

01 / GAMEPLAY

Responsive mobile experiences

I build touch-first mechanics and polished feedback loops for puzzle, simulation, fashion, and casual games.

  • Drag, snap and selection systems
  • UI flows and level progression
  • Animation, audio and haptic feedback
02 / ARCHITECTURE

Reusable Unity foundations

I design modular core systems that can move between projects without turning every new game into a rebuild.

  • Service-based project architecture
  • Shared managers and configuration
  • Phased upgrades across live projects
03 / RELEASE

Production-ready integrations

I connect the systems a mobile game needs after the core gameplay is working and keep release behavior predictable.

  • Ads, cooldowns and banner control
  • Music, sound and player settings
  • Analytics, remote config and build safeguards
I turn game ideas into responsive, scalable mobile experiences.

I’m a Unity developer based in Lahore, Pakistan, building Android games for the Sketchy Gamerz catalog. My published work crosses puzzle, hidden-object, simulation, fashion, and casual genres.

Alongside gameplay, I maintain a reusable Unity core module for the systems shared between projects. That includes service architecture, monetization behavior, audio, analytics, configuration, and release checks—work that helps new games start faster and existing games improve safely.

I care about both sides of development: the moments players feel immediately—a clean drag, a rewarding snap, a crisp transition—and the dependable technical foundation behind them.
